Les jeux, c’est vous qui les apportez

Cable Club ne contient ni jeu ni ROM, et n’en distribue pas. Au premier lancement, vous lui indiquez les fichiers de vos propres jeux (« Mes ROMs » sur PC, « Ajouter des ROMs » sur téléphone). Il garde vos fichiers sur votre appareil et ne les envoie jamais au serveur.

Une question à l’installation ?

Windows affiche « Windows a protégé votre ordinateur »

C’est l’écran SmartScreen. Il apparaît pour tout programme récent ou peu téléchargé, qu’il soit sûr ou non : Windows ne connaît pas encore Cable Club.

Pour continuer : cliquez sur Informations complémentaires, puis sur Exécuter quand même. Si vous préférez vérifier le fichier avant, comparez son empreinte avec celle affichée plus haut : dans PowerShell, Get-FileHash .\CableClub-0.11.0-windows-x64.zip doit donner la même suite de caractères.

Le code de Cable Club est public, et la version Windows est compilée par GitHub à partir de ce code : vous pouvez le vérifier.

Mon antivirus (Norton, Avast…) supprime ou bloque le fichier

Les antivirus se méfient des programmes récents et peu répandus, même sûrs : c’est ce qu’on appelle un faux positif. Cable Club se met aussi à jour tout seul et peut ouvrir un port sur la box pour héberger un serveur, ce qui ressemble à ce que fait un logiciel malveillant.

  1. Restaurez le fichier depuis la quarantaine de l’antivirus.
  2. Ajoutez le dossier de Cable Club aux exclusions (Norton : Paramètres › Antivirus › Analyses et risques › Exclusions).
  3. Vous pouvez aussi nous signaler le faux positif : écrivez-nous le nom de la détection à contact@cableclub.app, nous le transmettrons à l’éditeur de l’antivirus.

Si vous hésitez, comparez l’empreinte du fichier avec celle de cette page, ou analysez-le sur un service en ligne comme VirusTotal.

Android refuse d’installer le fichier

Android demande d’abord d’autoriser votre navigateur (ou le gestionnaire de fichiers) à installer des applications : acceptez, une seule fois, puis rouvrez le fichier téléchargé. Si un message parle du moteur web, mettez à jour « Android System WebView » depuis le Play Store.

Votre téléphone doit être sous Android 11 ou plus récent. Il n’existe pas de version pour iPhone ni iPad.

Comment me mettre à jour ?

Cable Club vérifie tout seul s’il existe une nouvelle version (Réglages › Autres › Mise à jour), la télécharge et l’installe en gardant vos données. Rien à refaire à la main.

Signature du code (Code signing policy)

Pour que Windows reconnaisse Cable Club, nous demandons la signature de code gratuite de la SignPath Foundation pour CableClub.exe. En attendant qu’elle soit active, le programme n’est pas signé : c’est ce qui explique l’avertissement de SmartScreen décrit plus haut.

Le code de Cable Club est public et la version Windows est compilée par GitHub : le fichier publié est celui qui sort du code que vous pouvez lire.
