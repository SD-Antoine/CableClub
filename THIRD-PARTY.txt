Universal Pokemon Randomizer ZX 4.6.1
  Auteurs : Ajarmar, darkeye, cleartonic et les contributeurs du projet,
            d'après l'Universal Pokemon Randomizer original de Dabomstew.
  Licence : GNU General Public License v3 (voir LICENSE.txt)
  Source  : https://github.com/Ajarmar/universal-pokemon-randomizer-zx
            (commit 7f00eb866ed35c8fe3963f078b6a2e0979dc2b8c)
  Usage   : moteur de randomisation, compilé sans modification dans
            upr-zx.jar. Le script build.ps1 du code source de SLT
            télécharge et compile exactement cette version.
            Version Android : la classe com.dabomstew.pkrandom.newgui.
            NewRandomizerGUI du moteur (sa fenêtre Swing, absente d'Android)
            est retirée et remplacée par une classe vide propre à Cable Club
            (android/app/src/main/java/com/dabomstew/pkrandom/newgui/
            NewRandomizerGUI.java, GPLv3), sans autre modification du moteur.

Cœurs d'émulation (libretro)
  Chaque binaire livré a une source connue (cores.lock.json) : la construction
  lit le commit dont il est issu (ou vérifie l'empreinte d'une version
  officielle), refuse un cœur dont la source serait inconnue, et l'écrit dans
  COEURS.txt (Windows) ou coeurs.txt (Android) avec son empreinte SHA-256.
  Chaque release GitHub joint l'archive des sources exactes de ces commits et
  tags : CableClub-<version>-sources-coeurs.zip.
